CPU & GPU

Per-core CPU load and Apple Silicon GPU utilization, sampled live with rolling sparklines.

Disk & network

Real-time read/write and up/down rates from 64-bit system counters.

Thermals & power

Thermal state and power draw, side by side, so you can catch throttling as it happens.

Top processes

Sortable, searchable list with helper processes grouped under their parent app. Kill or quit inline.

Menu-bar readout

Live CPU + GPU in the menu bar. Keep the window closed; the numbers stay with you.

A Local Inference profile foregrounds memory, GPU, and power for running LLMs on Apple Silicon.

Auto-updates

New versions arrive quietly via Sparkle — signed, verified, and installed on quit.

Install in seconds

  1. Download the DMG and open it.
  2. Drag Mac Resource Monitor into your Applications folder.
  3. Launch it. Signed and notarized by Apple, so no Gatekeeper warnings — and it keeps itself up to date.
